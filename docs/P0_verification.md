# P0本轮实现与验证记录

日期：2026-11-18。此记录描述开发验证结果，用户实际界面验收尚未完成。

## 实现范围

1. 修复Science Table 1定位。表注、同宽细横线与数字行共同界定表格，不再关联右侧独立图。没有足够定位证据时不凭空扩框。正文解析版本仍为v15，单独的几何版本升级只改坐标和表格主体区域，不清空摘要、批注、笔记、追问或用量。
2. 图表解读内置复核。生成后向同一视觉接口另起不含草稿的读图请求，按位置读取对象、数值、单位及箭头关系；随后对照截图、真实原文和读图候选核对四部分解读。这种独立读取用于减少草稿影响，不代表采用另一个模型或独立事实验证。支持、部分支持、不支持、信息不足分别处理，修正最多一轮且必须再次核对。极值比较增加数值一致性校验，不能凭模型声称“支持”直接放行。
3. 保留已确认内容。某部分失败不吞掉其余部分；图中观察未通过时，可将独立读取的逐项数值作为收窄候选再次核对，减少整段观察丢失。完全无可交付内容则明确失败、不保存草稿。图中候选本身并非事实金标，仍需图文核对。
4. 证据只保留文字、段号和相对位置。长图注可在3500字符输入范围内完整匹配，不截去发生错误的尾部；数字、单位或来源变化仍不得通过。图像证据坐标检查只能确认格式和范围，不能程序证明像素语义正确。
5. 完成任务导读真实样本检查和支持性金标评估。模型判断明细可折叠查看，无需用户主动点击核查。历史旧结果不自动付费迁移。

## 真实论文20条支持性金标

- 配置：`tools/evidence_gold.json`，12条真实ResNet/SMP原文判断、8条曲线/柱状/结果表/架构图判断；覆盖数值、指标、单位、缺失信息、假说强度、范围及连接错配。
- 原文及图像样本以PDF哈希、页码、原文定位片段或截图坐标固定。错误主张为测试拦截而故意改写，不代表论文原话。
- 可重复执行：`python tools/evaluate_evidence.py`只核对本地输入；加`--live`会发送固定选段与截图到配置模型，计费且不写应用书库。
- 最终结果：`.tmp/evidence-evaluation/run-20261118-155227.json`，四分类标签19/20一致。8条“支持”样本全部获支持，12条其他标签样本均未被判为支持；本集支持判定precision=8/8、recall=8/8。一条故意将错误率写成准确率的样本被判为“部分支持”而金标为“不支持”，没有放行。
- 前期结果保留：`.tmp/evidence-evaluation/run-20261118-153846.json`为18/20，含一个正确样本误拒绝与一个分类不一致；`.tmp/evidence-evaluation/run-20261118-154253.json`记录独立读图后的8条图像子集。不得只展示最终数字而抹去漏检历史。
- 这些是开发用小样本，不构成总体准确率；重跑可能变化。不得把模型复核与开发助手金标称为独立人类验证。自创术语precision/recall和独立用户实验仍为后续任务。

## 任务导读

`node tools/evaluate_reading_goals.cjs`读取ResNet、SMP、Science的实际书库，检查三种目的的候选段号组合有差别、无越界、各已有入口有有效页码和热区。输出在`.tmp/reading-goals-real.json`。课堂组会包含图表入口；复现入口缺失时保留未知，复现模块只在准备复现时显示。此检查确认入口差异与可定位，阅读帮助程度仍需用户实测。
