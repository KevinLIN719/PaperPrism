# PaperPrism 浏览器体验版

三篇现有书库论文：计算机（Transformer）、劳动经济学（Generative AI at Work）、机器人（Continuous Self-Modeling）。每篇有一个真实生成的分层讲解、一个预设追问、一个图表解析，共九个可点击示例。原文 PDF、图表截图、模型结果均随静态文件提供，现场访问不调用模型。

## 本机展示

在项目根目录执行：

```sh
python -m http.server 8877 --directory browser-demo/dist
```

打开 http://127.0.0.1:8877 。不要直接双击 HTML，浏览器需要通过 HTTP 加载 PDF 和 JSON。

## 部署

把 `dist` 目录里的全部文件上传到任意静态网站根目录即可，无需后端、构建或 API Key。文件使用相对路径，支持 GitHub Pages 的 `/PaperPrism/` 子路径。

GitHub Pages：提交本次文件并推送 GitHub 后，将仓库 Settings → Pages → Source 设为 GitHub Actions，再手动运行 `Deploy browser demo` 工作流。工作流仅发布 `browser-demo/dist`，不会上传本地书库、笔记、模型配置或 `.env`。成功后的地址以 GitHub Actions 显示为准。

也可上传根目录下 `paperprism-browser-demo.zip` 到自己的静态托管服务（解压后以 index.html 所在目录作为网站根目录）。

## 现场操作

1. 从原版顶部下拉框选择论文，自动打开已有解析和摘要。
2. 点击右侧“预生成讲解”，定位示例段落，在“本段”展开分层讲解。
3. 点击右侧“追问示例”，展开原版追问记录，引用仍可定位原文。
4. 点击右侧“图表示例”，展开缓存解读并定位原图选区。
5. 在原版左侧书签入口添加彩色书签、编辑问题；“本段”可保存个人批注。
6. 右侧 GitHub 链接可进入完整版仓库，运行方法见仓库 README。

页面直接沿用 `web/reader.html` 的原版配色、排版和右侧栏，以及原版彩色书签、笔记、缩放、原文跳转。书签和笔记通过浏览器 localStorage 保存，刷新及切换论文后恢复。浏览器清理网站数据后会丢失，可以使用原版“导出阅读笔记”下载备份。

实时 AI 功能（自由追问、重新生成摘要/批注、任意段落讲解、新图表解读、复现评估、跨论文 AI 对照）以及联网搜索已锁定。预生成讲解、追问和图表解读通过右侧栏按钮进入，显示在原来的“本段／追问／图表”区域。框选图表仍可操作，但不能现场生成新解读。未缓存段落明确提示锁定。

页面明确标注结果预先生成。自由追问、任意上传、实时分析请使用完整版。原文核对是辅助检查，不能保证模型解释完全正确；追问可能仅保留核对支持的部分。

## 更新缓存

```sh
python tools/build_browser_demo.py
```

此命令从三个明确指定的本地书库条目中提取解析、摘要与批注，不导出个人笔记和追问历史。缺少的示例通过项目配置的模型生成并核对；图表会向配置的视觉模型发送指定截图。已有缓存复用。删除指定结果字段后再运行才会重新生成对应示例。不要把 `.env` 或 `settings.json` 放进 `dist`。
